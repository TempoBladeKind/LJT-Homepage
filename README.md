# Junteng Liu — Personal Homepage

Personal academic homepage of **Junteng Liu**, Ph.D. candidate at the HKUST NLP Group.

- **Live site:** https://TempoBladeKind.github.io/LJT-Homepage (once GitHub Pages is enabled)
- **Built with:** the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template (Jekyll)
- **Deployment:** GitHub Pages via GitHub Actions (`.github/workflows/jekyll.yml`)

## Pages

- `/` — Home / bio
- `/about/` — About
- `/cv/` — CV
- `/publications/` — Publications
- `/talks/` — Talks

## Local development

```bash
bundle install
bundle exec jekyll serve --baseurl "/LJT-Homepage"
```
